# 08 — Composition, occlusion, LOD, and performance

**Contract:** the complete native frame keeps the browser's readable subject scale, occlusion order, authored density, and bounded work while exposing real cost.

**Seam:** one native frame orchestrator with explicit phases: resolve capture frame, update units/fog/effects, update camera, draw terrain/models/grass, draw atmosphere/post, then overlays. Culling/LOD budgets remain renderer-only and report every omission.

**Runnable checkpoint:** full 24-cut display-backed market-town/paris-corner reel at the matched viewport with paired controls and final resource report.

**Focused gates:** authored visible-row coverage, no duplicate shell/box, no fog grid read, no stalls/leaks, CPU submission time, GPU timestamp, transfer, memory, shader compile, and presentation cadence. Compare foreground interleaved browser/native runs on the same machine and workload.

**Visual variable:** whole-frame composition and cost. Earlier slice verdicts must already be green.

**Acceptance evidence:** full-cut `compare-screenshots`, unprimed `screenshot-critique`, `preview-shots`, and performance report. Do not promote from FPS alone.
