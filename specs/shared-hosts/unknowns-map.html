Shared hosts: buildings and transports admit squads alike

Unknowns map from the 2026-11-16 walk. Several squads share a host while seats remain; a squad gets in when it arrives and fits.

Superseded in part by the plan (README.md, decisions.md, slices/)This map is the record of how the decisions were reached. Where it differs from the plan, the plan wins: card 3's "window-change time moves to the soldier" is reversed (it stays per window), card 5's per-squad route proof is replaced by the old Garrison lowering with no proof, and the "Confirm before coding", "Tweakable plan" and "Implementation prompt" sections are replaced by README.md and the slice files.

1 · Known knowns

Transport todaySeats per unit type (3, 8 or 16), one per living soldier, squads board whole, any number that fit (carriage::seats, seats_used, crates/sim/src/carriage.rs). Board and Collect accept closest-first at the command and refuse the rest with CapacityFull (crates/sim/src/battle.rs:3170–3205).
Building todaySeats = exposed window bays on the bottom three floor bands, capped by buildings.capacity_soldiers (seat_plan, garrison.rs:119). One squad only: OneSquadPerBuilding, BuildingOccupied at the command (garrison.rs:275); any squad of either side inside makes a late entrant give up (garrison.rs:262).
Shared machineryOne enter / inside / exit state machine for both hosts (hold::advance, hold.rs:172). Each host uses one timer for both directions (Host::timing, hold.rs:32).
HistoryOne squad per building was the user's own call on 2026-09-28, "for simplicity" (specs/done/battle-look/decisions.md:500). That change deleted the waiting phase, the command-time occupancy sum and slot sharing between squads. This walk reverses it.
OrdersPlayers enter with OccupyBuilding (preview, one entrant plus gathering companions, garrison/occupy.rs). Garrison is sent only by the encounter defender (encounter/defender.rs:28), labs and tests. Riders can't be ordered; garrisoned squads can.
Assumptions keptSquads enter whole, never split. One side in a building at a time. Building capacity stays the bay count. Not-a-building, not-infantry and enemy-inside failures stay.
