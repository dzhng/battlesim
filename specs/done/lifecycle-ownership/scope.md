# Scope decisions

This is the complete disposition of the 2026-11-06 audit at planning baseline
`0a156e668e6077c2c3f4d8b17158f60fb3724b2e`. **16 families change; 69 stay.** IDs
preserve audit provenance, not a permanent architecture registry. Each row has a
firm disposition; there is no conditional implementation bucket.

“Change” names the selected part of that family, not every helper nearby.
“Keep” means no state representation or policy conversion in this feature;
consumer imports and regression checks may still follow an adjacent change.
Existing explicit Hold/Pass/navigation/skirmish phase owners also remain intact.
