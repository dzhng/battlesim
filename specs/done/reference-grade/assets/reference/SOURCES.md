# Colour-grade reference

`norwegian-tank-afghanistan.jpg` (1024×682), supplied by the user from
https://pbs.twimg.com/media/HWi5bydX0AAKTQs.jpg?name=large. It is a photo of a
desert-tan Norwegian armoured vehicle on green hills under a soft overcast sky,
and it is the colour response the whole game is lit to. Use it to review a
change only. It never ships and nothing in the runtime or the tests reads it.

It is Git LFS: `git lfs pull --include="specs/done/reference-grade/assets/reference/**"`.
