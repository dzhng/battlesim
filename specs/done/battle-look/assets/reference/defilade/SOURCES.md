# Defilade reference frames

Third-party, copyrighted frames from *Defilade* (RBGames), kept only as visual targets for this spec's
screenshot comparisons, with the user's permission (2026-09-25). Not game assets; never ship them.

- `steam-1..5.jpg`: the five 1920×1080 store screenshots, https://store.steampowered.com/app/5246700/Defilade/
  (1 desert battle, 2 winter base + HUD, 3 desert infantry and explosions, 4 winter village fight, 5 desert town).
- `trailer-t<N>s.jpg`: 1920×1080 frames at N seconds of the Steam trailer (HLS on the same page).
- `x-<name>.jpg`: poster frames; `x-<name>-f<k>.jpg`: the k-th of 8 evenly spaced frames of the video,
  from posts by @Neucollective on X (https://x.com/Neucollective/media):
  refined-explosions (status 2103602352485957905: snowy furrowed fields, tree line, craters),
  realistic-explosions (2102861971586732299: winter village, explosions), shader-craters (2091609860630528283:
  mud-through-snow roads, craters, tracers), trenches (2090943852492296317), close-combat (2091177150837596584),
  saving-wounded (2097439579649294805: close zoom on soldiers and a tank), large-scale-war (2098524624858276201),
  apc-assault (2091609884038950956), hind-hmg (2101449810112848216).
