# Exploration audio

Everything generated during the discovery walk (2026-10-11), kept per the user's rule that every generated asset is kept. Nothing here is served or read by code.

- `<set>_<n>.mp3` + `.json`: the three Voice Design candidates (A/B/C = 0/1/2) for each of the four reference voices; the `.json` holds each preview's temporary id. Picks: us_tank C, ru_rifle B, us_recon B, uk_pilot C.
- `*_radio*`, `*_earpiece`, `*_intercom_rotor`, `*_outdoor`: processing variants auditioned for treatment (T2).
- `combat_*`, `tension_hybrid`: round-1 music directions (rejected as foreground). `u_*`: round-2/3 background sketches (Pulse chosen; arp, drums, drone rejected). `ctx_*` / `ctx26_*`: the same sketches mixed under a battle bed and two voice lines.
- `bed_*`: generated beds (tank interior, helicopter cockpit, distant battle).
- `premade/`: premade ElevenLabs voices with accent tags, compared against a designed voice and rejected.
- `cue_voices_*`: the old synthesized murmur for unseen infantry, replaced by the muffled shout cue.
