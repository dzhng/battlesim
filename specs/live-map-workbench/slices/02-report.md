# Native report and publication

Unlock one exact input snapshot → validated settings → accepted retained artifact or exact refusal, with explicit reviewed source publication.

Add a native developer example under mapgen using its existing sim dev-dependency. stdin JSON commands validate, generate, inspect retained plan and measure sight. Generation runs once and compiles that plan through existing lower. Return compact SVG, geometry/country/compile metrics, selection metadata and separate encounter readiness; retain the exact plan/map/sites/inputs server-side for crop and analysis operations. Do not materialize two generated worlds just to inspect.

The local source-only app is apps/map-workbench; its Vite middleware is dev-only, local/same-origin and path-allowlisted. Use existing web dependencies. Snapshot reads presets/defaults and read-only templates/rules/catalog/recipes; its revision covers exact input bytes. The native process gets a captured bundle and never reads drifting paths on its own mid-job. Browser sees opaque artifact IDs, no filesystem paths. HTTP abort and server close terminate owned native children. Retention is bounded to active work plus saved/latest candidate comparison artifacts; clean on disposal. Report payload limits must cover measured Large output, not truncate it silently.

Publication mirrors mechanics guarantees: native-valid candidate, exact before/after replacements and managed preset revision, then commit that exact reviewed candidate after rechecking all source receipts. Valid settings save despite seed refusal. Stale/external edits return a conflict retaining the draft and outside bytes. No-op save is idempotent. Two editable files need recoverable journal/atomic replacement primitives shared with mechanics, not a second unit/inheritance store. Never expose generic file writes.

Typed seam (same names may be improved consistently): Snapshot { revision, documents:{presets,defaults}, receipts }; Draft { revision, documents }; Choice is existing MapChoice. Report { fingerprint, choice, status, diagnostics, artifactId?, svg?, groups?, metrics?, counts?, encounter?, timings }. Validate/preview returns exact candidate and files; save accepts reviewed candidate token. Inspect and sight accept an artifact ID bound to source/fingerprint. Preserve source fingerprint versus map/config identity meanings. Exports contain full tested input documents.

Gates: public store tests against scratch files for no writes on preview, invalid save, refused-but-valid save, stale save, outside edits during publication and interrupted publication recovery. Native tests compare report output against production generation on matched input; inspector crops read the same artifact. No timing/validity mock becomes the business-rule oracle.

Run surface: native stdin report and GET snapshot/POST validate, generate, inspect, sight, preview/save. A dedicated build:map-workbench command builds the native example once; normal dev and dev:maps make it available. Add app README explaining capture/publication/lifetime principles.
