# Choices

User decisions and their reasons are recorded in the decision map and carried as givens by the README. This ledger records architectural choices where that walk left freedom.

## Sound — medium confidence

### Native developer reports, exact production preparation

When: planning. When a local draft needs a plan picture and sight measurements, a cancellable native developer process calls the existing Rust owners and returns compact inspection/report data. The alternative would add large developer-only Wasm output/session APIs. The local-only editing contract and existing mapgen sim dev-dependency make native execution the smaller boundary. Future production generation remains unchanged.

### Released admission is not the current generation work allowance

When: planning. Lowering a generation cap makes new generation refuse earlier; it does not forbid an already released saved battlefield. Saved-map admission retains its fixed supported ceiling, and mutable production generation part/bay allowances must fit that ceiling. The alternative couples a tuning slider to fallback validity and makes Play reliability depend on the failed settings. This is a named replacement of the equality contract by containment, requiring behavioral proof.

### Report policy stays distinct from mandatory admission

When: planning. Editing a target for median sampled openness changes the diagnostic pass/fail of that measured report, not the physical whole-cell certificate. The alternative would quietly add expensive sight analysis to every gameplay preparation and call a finite sample a continuous proof. Analysis policy belongs with generation defaults and has its own fingerprint.

### Latest pending work, not a request queue

When: planning. If A is running while the user types B then C, only the latest pending C survives. A's response remains identified as A and cannot be labelled current. This preserves forward progress and limits work to one child plus one pending request. Samples can yield/cancel to a foreground edit while retaining completed rows.

## Open measured choices

Concrete player retry/deadline headroom and optional automatic-sight envelope are owned by their slices. Do not promote provisional numbers to passing claims until measured.

## Sound — implementation decisions

### A runtime fault goes straight to the released fallback — medium confidence

If a candidate fails because of an unknown worker/runtime error, ordinary Play tries the independently resolved saved battlefield once. A known placement/generation exhaustion can try a fresh seed first. Repeating a seed-independent runtime fault would spend the allowance without improving the outcome. Each attempt retains its message, stage and diagnostics for developer evidence.

### Seed collision advances within the same u64 domain — high confidence

If random selection returns an already tried seed, selection increments it modulo the unsigned 64-bit domain. Sample sequences use the same domain, wrapping from its maximum to zero. This keeps requests valid at the boundary and avoids an unbounded random redraw loop; each actual seed is recorded.

### Cancellation returns the unadmitted preference — high confidence

Before ordinary Play admits a battlefield, Cancel returns type/size preferences without a seed. After admission, the page and replay use the winner's exact request. This prevents the placeholder used to construct a candidate request from accidentally becoming a promised map identity. Cancelled preparation keeps its existing silent-promise contract and closes its worker.

### Refusal receipts do not evict an inspectable accepted map — high confidence

When the newest draft refuses, the tool retains the prior accepted geometry and marks it older. It keeps the newest refusal's exact tested inputs separately as a small receipt. A sample exports each receipt immediately because only its latest admitted geometry is retained; returning to the editor regenerates its selected map. This bounds stored geometry while preserving truthful diagnostics and reproducible samples.
