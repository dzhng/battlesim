workers and their presentation do not receive edits. Suppress HMR reload for

rejects invalid combinations. Verify a running battle remains running and an
explicit restart gets the latest accepted values. Do not mutate shipped tuning
for verification. Run focused checks, then the named closeout gates once.

run unprimed screenshot-critique last, and show with preview-shots. Complete
whole-feature review, consolidate choices, commit and close-spec. Report any
