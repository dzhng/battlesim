Each has steady/stressed × 2 takes. A unit is stressed when health is ≤ ½ or it is suppressed.user

4 · Unknown unknowns landmine cards, worst first

L1 · The ElevenLabs account is small decided (A6)
evidenceThe plan was Starter: 3 concurrent calls, ~10 slots. It is Creator now (5 concurrent verified), still ~30 slots and ~100k credits a month (slots, pricing). The balance can't be read (user_read denied).
bitesWe need ~55–60 voices and ~110k characters, on a shared account.
changesVoices are saved only while in use, reference clips live in the repo, and the pilot set comes first.
L2 · Size and loading would stall battle audio decided
evidenceBattleAudio.connect waits for every assigned sound, one at a time (battleAudio.ts:67-72, soundBank.ts:23-37). WAV is 96 KB/s. Menu music decodes a whole 28 MB WAV.
bites~450 MB of voice WAV, ~100 MB of music, and thousands of serial fetches before battle sound starts.
changesMono MP3: ~40 kbps for voices (~20 MB total), 128 kbps for music (~15 MB). Voice sets load in the background after ready, only for the sets in the battle; a bark whose clip isn't loaded yet is dropped. Music streams through a media element.
L3 · The catalog ships inside the JavaScript bundle decided
evidenceshippedSounds.ts imports sounds.json (216 KB for 232 clips).
changesVoice clips are not entries in sounds.json. Their path is a convention: voices/<set>/<trigger>-<intensity>-<take>.<hash>.mp3. voices.json loads with the battle.
L4 · Shout state on units would change every digest decided
evidenceUnit::digest folds the unit's complete state (units.rs:565). Observations are not digested (battle.rs:280). combat_rng is digested and drives the menu reel (battle.rs:3766, tests/menu_reel.rs).
changesCooldown and talking state live with each side's observation builder. There are no simulation RNG draws. Digests must stay unchanged; a digest change counts as a bug.
L5 · Publication bytes are pinned sharp edge
evidenceThe new group goes in GROUP_LAYOUTS (publication.rs:417-470), modelled on audible (:234,451). publication_sha256 in fixtures/parity/publication/*.json and codec-vectors.json changes.
changesOne named re-bless (BLESS_PARITY=1): the bytes change and the digests don't. Old replays are already refused by build fingerprint.
L6 · The validator assumes third-party crops decided (A4)
evidencecatalog.ts:105-150. Paid ElevenLabs plans allow commercial game use, and ElevenLabs keeps training rights (summary).
L7 · Caching and deployment decided + OPEN
evidenceClips are served at non-content-addressed /audio/clips/*.wav, outside the immutable /:sha/ rule (vercel.json). The Vercel install never runs git lfs pull (web/README.md:41-45).

OPEN items

O1 · Where the callsign comes from OPEN, your call
T3 says callsigns are invented per unit, but D4 shares recorded lines across a whole set, so a callsign baked into shared audio would be wrong for every other unit type in that set. Options: (a, recommended) one callsign per voice set ("Oscar two-one" for every US tank crew), spoken only in R1 selected and R11 arrived; (b) record R1 and R11 again per unit type with its own callsign, about 700 more clips; (c) no callsigns in audio, shown in the UI only.
O2 · Accent for generic European infantry OPEN, your call
European Rifle, Assault, Marksman and Recon Patrol squads have no obvious country. Options: (a, recommended) British, the faction's only native-English army, which reads clearly; (b) German; (c) mixed, so each squad's 2–3 voices are different nationalities.
