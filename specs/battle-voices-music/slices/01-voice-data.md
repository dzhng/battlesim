# 01 — Voice data

**Contract this unlocks:** `fixtures/voices.json` exists, is validated, and resolves every playable roster unit, for every faction that fields it, to a voice set with scripts for all 29 triggers. This slice makes no network calls.

## Seam

**`packages/battle-audio/src/voices/voiceCatalog.ts`** exports:
- `VoiceCatalog`;
- `validateVoiceCatalog(json, roster)`;
- `RESPONSE_TRIGGERS` (R1–R12) and `BARK_TRIGGERS` (B1–B17, snake_case);
- `lineText(catalog, set, voice, trigger, intensity, take)`, which expands `{callsign}`.

**Schema:**

```jsonc
{
  "roles": { "<role>": { "lines": { "<trigger>": { "steady": [t0, t1], "stressed": [t0, t1] } } } },
  "sets": { "<set>": {
      "role": "<role>", "country": "us|de|uk|fr|se|it|ru|cn", "callsign": "Oscar two-one",
      "processing": "voice-radio-light|voice-dry|voice-earpiece|voice-intercom",
      "voices": [ { "id": "lead", "speaks": "responses|barks|all", "gender": "male|female",
                    "description": "…", "voice_id": "…|null" } ] } },
  "assignments": { "<unit type>": "<set>" | { "<faction>": "<set>" } },
  "retakes": { "<set>/<voice>/<trigger>/<intensity>/<take>": 1 }
}
```

**Line text:**
- Lines may carry ElevenLabs v3 audio tags such as `[shouting]`, `[panicked]` and `[whispers]`.
- Stressed lines may swear.
- `{callsign}` is legal only in R1 and R11, and the validator enforces that. B17 lines are generic.

**`Generated` provenance:** this kind is added to `catalog.ts`, next to the existing licences, and voices import it.

**`packages/battle-audio/tools/generate/` is created here.** Its `plan` command prints:
- for each unit: its set, country, role and voices;
- the total clip count and total characters.

That output is the generation budget the pilot (slice 04) checks.

## Data this slice authors

**Roles** cover every kind of unit in the roster. Name them yourself, but cover at least:
- tank crew, IFV/APC crew, recon vehicle crew, supply driver;
- rifle squad, assault squad, marksman squad, recon infantry, sniper team;
- ATGM team, MANPADS team;
- attack-helicopter pilot, transport-helicopter pilot.

**Sets:** about 40, one per country × role that actually occurs. Accents follow the rule in `choices.md` → "Accents per unit":
- infantry uses its faction's default nationality (US, German, Russian), except national teams;
- vehicles and aircraft use their country of origin, with the listed picks where several nations built them.

About 6 sets are female (`choices.md`).

**The four saved voices** (`assets/saved-voices.json`) fill `us_tank`, `ru_rifle`, `us_recon` and `uk_pilot` with their real `voice_id`s. Every other voice has `voice_id: null` until slice 05.

**Squads:** one `lead` voice that `speaks: responses`, plus 1–2 soldier voices that `speak: barks`. Sniper teams and 3-man teams get 2 voices; squads of 6 or more get 3.

**Scripts:** written as short, war-film radio and shouted speech, matching the samples the user approved. The reference audio in `assets/reference-voices/` gives the register. Stressed takes should *sound* stressed in the text too.

## What the human sees

`specs/battle-voices-music/visualizations/voice-sets.html` is generated by `plan --html`. It shows:
- every roster unit with its set, country, accent, callsign and female flag;
- each role's script.

## Verification

- `web/tests/voiceCatalog.test.ts` checks that:
  - every role covers 29 triggers × 2 intensities × 2 takes;
  - `{callsign}` appears only in R1 and R11;
  - every playable roster unit resolves to a set for each faction it fields (from `fixtures/units/roster/*.json`, including shared rows);
  - the four saved ids are present;
  - test and menu units resolve to no set.
- `plan` runs and prints the totals.
