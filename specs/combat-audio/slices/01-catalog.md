# Catalog and media

`SoundCatalog` is the authoring contract. Sources retain hashes and URLs; clips
retain exact source frames, processing, mono runtime URL/hash and perceived role.
Recipes keep distinct families separate and retain all synthetic baselines. A shot
assignment rejects reload/mechanical/loop assets. Source metadata is fixed during
workbench recipe/assignment saves.

Extract clean individual reports, not whole bursts. Record user-directed split
regions in the extraction owner. Keep useful unassigned handling clips. Initial
choices are delegated: crisp rifles, heavier bass for high calibre, restrained
support. This includes ATGM, cannon, ricochets, small/heavy ground impacts and blasts.

Proof: test assignment independence and invalid references/roles first; validate
every runtime WAV, source hash and exact crop; reproducible audio rebuild/check.
Auditory identity remains provisional where only annotations/metrics establish it.
Library is playable in the workbench; visual acceptance belongs to slice 3.
