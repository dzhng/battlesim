# S6: finite-template generation parity

**Depends on:** S2's legal template descriptors; S0 for full-extent resource limits. **Kind:** throwaway spike.

## Question
Can the same Rust generator materialize a legal varied template map natively and through wasm, without a per-map art job?

## Contract it unlocks
`spikes/S6.md`: a disposable finite geometry catalogue, generator entry point, native/wasm parity evidence and timing/memory rows. Prototype descriptors may use labelled missing-category boxes; they do not count as release art.

## API seam
Lossless request `{type, size, seed, generator_version, preset_revision, template_catalog_hash}` + finite template geometry manifest → canonical map, immutable identity and stable diagnostics. Use a canonical decimal string for the u64 seed at JSON/JS boundaries; never route arbitrary u64 map seeds through a JS Number/f64. One Rust algorithm serves CLI and wasm.

Templates declare physical parts, floors/floor heights, entrances, exposed edges and supported joins. Select legal templates before filling parcels; rotate/translate them without changing metre scale. The map stores physical template IDs/frame and materialized geometry. Compatible art resolves separately through C32. Probe compatibility with adjoining templates and unsupported fits without calling Blender.

## What the human can run or see
A matched CLI/browser request and plan overlay, identical map/hash/diagnostic reports, class × family coverage and explicit missing-template failures.

## Verification
- All nine type × size requests over matched fixed seeds and template hashes; compare complete canonical outputs, IDs, template choices, roads and failures.
- Boundary seeds, including values above JS's exact integer range; native/wasm identity remains equal.
- Finite catalogue limitations produce bounded local diagnostics, not stretching, another seed or runtime graph evaluation.
- Record generation/lowering time and peak memory within S0's safe limits.
- Freeze successful inputs/dependencies/results by hash for C04/C53/C55 parity.
- Visual variable: template fit and composition only. Compare overlays using compare-screenshots, run unprimed screenshot-critique last, and show shots with preview-shots non-blocking.

## Delegated to the implementer
Throwaway catalogue contents and adapter plumbing. Canonical encoding and physical-catalogue/appearance identity contract are named G0 outputs.

## Must stay green
Production code; no production generator or second map format merges from this spike.

## Feedback that would change this slice
An insufficient variety/fit result expands the template proposal or changes legal parcel composition at G0.
