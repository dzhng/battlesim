# S7: plan-only composition trials

**Depends on:** S0's safe experiment limits. **Kind:** throwaway spike.

## Question
Which numeric presets express the accepted type/size character, fairness and useful open approaches?

## Contract it unlocks
`spikes/S7.md`: cheap plan overlays at every fixed extent, composition proposals and geometric access/range criteria. No simulation, Blender or production mapgen implementation is required. S1 later proves physical access and battle cost.

## API seam
Disposable layout polygons/labelled template boxes → measured town/building counts, category weights, urban/plain/forest shares and top/bottom town-area/forest-coverage differences. Model stable metre scale and more settlements at larger sizes; Metro has a central city and satellites. Layout trials preserve all accepted category exclusions and use one forest rule.

## What the human can run or see
Nine type × size overlays over multiple seeds, with proposed fairness tolerances and useful 1,800 m approach/range corridors drawn at metre scale.

## Verification
- Exact current M04 bounds from [the map-design brief](../procedural-maps.md#closed-decisions), stable dimensions, regional/category eligibility and non-mirrored comparable coverage. Include road access/connectivity and the [transit target](../scale-direction.md#vehicle-transit-target) in layout trials.
- Count proposals are derived from full-extent composition; historical 500/1,500/3,000 samples are stress inputs only.
- Draw [playable bounds and the wider rendered surroundings](../scale-direction.md#playable-area-and-rendered-surroundings) separately. Measure playable fairness/access within M04 and scenery coverage outside it; do not substitute the outer rectangle for encounter placement or travel distances.
- Separate geometric corridor candidates from physically proved routes; S1 owns the latter.
- Compare layout/coverage masks to the accepted schematic via compare-screenshots; material/lighting/art quality are out of scope. Run unprimed screenshot-critique last and preview-shots non-blocking.

## Delegated to the implementer
Trial layouts and numeric proposal sweeps; G0 ratifies production values.

## Must stay green
User givens; no production code merges.

## Feedback that would change this slice
A rejected type character or fairness result changes its numeric proposal.
