production publisher counts the borrowed iterator, admits the complete record, then
writes it once. The browser retains the compact payload and applies it to the same
learned-page owner used by ground sampling and foliage. Small oracle tests alone expand

in `animation-codec-vectors.json`. They preserve the animation/garrison codec when its
test-only wasm JSON serializer is removed. The browser test rewrites only that fixture's
ground tail to the new representation. Its old synthetic cells were unordered, and its
new-epoch delta lacked a full baseline; the migration makes those synthetic ground inputs
valid. It does not change any animation, soldier, projectile or garrison lane. Native
wide-field tests now call the serializer used by Publisher itself.

must match. Prior observations retain their own payload after credits return.
