# Ground transport

Ground delivery sends exact tile-local runs straight from learned knowledge. The publisher counts the borrowed iterator, admits the complete record, then writes it once. The browser keeps the compact payload and applies it to the same learned-page owner that ground sampling and foliage read. Only small oracle tests expand runs back to the original tile order.

[`animation-codec-vectors.json`](../../../../fixtures/parity/ground/animation-codec-vectors.json) preserves the animation and garrison codec now that its test-only wasm JSON serializer is gone. The browser test rewrites only that fixture's ground tail to the new representation; its old synthetic cells were unordered and its new-epoch delta lacked a baseline, so the cutover makes those inputs valid without changing any animation, soldier, projectile or garrison lane. Native wide-field tests call the serializer the publisher itself uses.

The original movement observations stay in the [fog oracle](../../../../fixtures/parity/fog/oracle.json). Tests normalize only the ground representation, including the visible projection `tracks = max(raw tracks, clearing)`; digests, values, cursors, sides and every other lane must match.

The [transport verdict](../../spikes/SA3-transport.md) separates codec correctness from full-size workload admission and GPU frame cost.
