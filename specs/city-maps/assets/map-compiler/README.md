# Physical compiler proof

The [choices ledger](choices.md) records the admission, identity and boundary decisions
that subsequent compiler arms inherit.

The labelled asymmetric API descriptor is the existing C00 oracle. It exercises a
compound, joins, entrances and bay positions; it is not an accepted regional art
source. The compiler materializes it through the same contract owner the battle
loads. Original C00 records remain unchanged, with only C01's authoritative local
edge intervals added by the existing explicit test adapter.

`request.json` contains physical scalars that exposed the old JSON reader's one-ULP
rounding and a seed above JavaScript's exact integer range. The native corpus records
complete CLI outputs, including refusals. Its capture snapshot reproduces those
records to a separate destination; rerunning it does not authorize replacing an oracle.
WASM tests compare exact outcome bytes, and native tests reload the saved map and
verify the physical content hash. No JavaScript-number seed conversion or renderer
interpretation stands between these boundaries.

The contract's existing exact physical token reader now owns template, ordinary body
and map-header numbers. Flattened authored/event envelopes preserve raw tokens until
that existing owner decodes geometry. Scenario rules and simulation trig are unchanged;
this proof does not resolve S6's separate old formation arithmetic discrepancy.

Execution limits are independently tested at their accepted boundary and one unit
below. The map and generation identity are invariant when only admission policy changes.
Playability bounds are tested at the architecture envelope and just above it. This
preparation proof does not instantiate a full-size battle or establish global startup,
memory, navigation or rendered-surroundings capacity.

Nonempty surface/region/river/forest compilation, source/art fit and the visual inspect
overlay remain open. See the compiler slice for dependencies and the shared scale
policy for current release sizes; old scale receipts retain their original labels.

## Surface schema disposition

`pre-surfaces/` retains the original raw native corpus and source checkpoint.
`surface-disposition.json` verifies that the original successful outcomes change only
the empty `roads` field to `surfaces` and the resulting map content hash. The plan hash,
seed, physical catalogue identity and every physical geometry word remain exact.
Original unrelated refusals retain their complete bytes. The shared empty surface layer
is now admitted; a nonempty surface has an explicit pending-admission refusal. The
additional malformed version identifiers are separate new cases.

## Final gates

The [gate logs](gates/) retain each focused red/green arm and the final native/web,
format, clippy and TypeScript results. `identity.json` pins their hashes, source
checkpoint and the production WASM. `rejected-height.json` retains the complete
old acceptance that admitted an infinite derived height; the final native and WASM
tracers refuse it. `corrected-height.json` also records the exact matching CLI/WASM
refusal, reproduced by the height capture snapshot. All existing successful compiler
outcomes stay byte-exact.

The configured Codex CLI review was unavailable because its default model was
unsupported. Root independently reviewed the full source and found no remaining
issue after the proved height and version-identifier corrections. No CLI review
success, full-world capacity, universal simulation parity or art/source acceptance
is inferred from these focused gates. Combined check/verify belongs to integration.
