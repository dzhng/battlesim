# Native learned-ground work

The [baseline receipt](baseline/identity.json) freezes the integrated run-seam source,
probe and executed native rows before the learning-work correction. Its public path is
ground clear/seal, two independent KnownGround learning owners, the production serializer,
two retained credit-sized copies, resynchronization and hidden/revealed corner edits.
It excludes Battle, wasm, JavaScript and GPU ownership; its memory verdict is not whole
battle admission. The probe enforces a 4 GiB requested-heap ceiling before system
allocation; exit 70 is a failed resource arm, never lost ground or NoRoute.

The 18 km baseline retains all 324 million cleared cells and sends a 21,515,740 B
snapshot. Peak requested heap is 550,782,696 B; maximum RSS is 646,037,504 B. Values,
side separation, original retained copies and the one-cell reveal delta pass. Memory
fits this isolated uniform workload.

CPU work fails: each initial full learning pass retires about one trillion instructions
and takes 44–47 seconds. Unchanged learning retires 3.85 billion instructions and takes
209–213 ms per side; one visible edit still costs 205 ms. Counting and writing the full
snapshot take 44 and 50 ms. The snapshot is an exceptional reconnect operation, while
unchanged/one-edit learning is recurring tick work and exceeds the simulation budget.

These rows support the [focused work correction](../../slices/SA3-exact-learning-work.md).
Keep them immutable; corrected code/configuration and resource results get a separate
receipt. Timing and instructions are distinct measurements. All resource arms run
serially under the shared slot.

visibility words and visits edited tiles or newly visible ground. Fully visible pages
share immutable truth; edits use copy-on-write, and only changed visible values acquire
new learning stamps. Partial edge holes stay blank and unstamped. The ceiling-partition
oracle checks fractional fog grids, reveals, grid changes and unsealed direct API edits.
