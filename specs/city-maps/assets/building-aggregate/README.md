# Aggregate physical ownership evidence

The original production observations and battle traces are preservation oracles. They
are never refreshed from the aggregate implementation. New test inputs author the same
physical boxes through the C00 preparation seam, retaining their original PropIds,
poses, fitted appearance and seats. Only deliberate identity columns and the separate
C02 input-field relocation are normalized when comparing those original outputs.

The [native outer tests](../../../../crates/sim/tests/buildings.rs) exercise one integrity
across asymmetric parts, strongest once-per-blast damage, terminal replacement chains,
exposed seats and sensing eyes, hidden knowledge, clicked-part admission, bounded IDs,
and the immutable/public-versus-active owner distinction. The
[browser outer test](../../../../web/tests/buildings.test.ts) uses production WASM,
public map geometry and the actual picker before decoding atomic replacements.

The animation receipt is produced by the simulation's production serializer. Its
native test compares every original animation/header/fog word after exactly the new
owner limb split and KnownProp identity additions. Ground values retain the separately
frozen transport oracle; browser preparation rewrites only that original fixture's
unordered synthetic cells and missing full baseline, as documented in the
[ground transport evidence](../ground-transport/README.md). A labelled wide-ID arm
proves distinct identities beyond float32's exact integer range.

The frozen producer snapshots and JSON identities make the evidence reproducible.
Source discovery distinguishes immutable building facts from live physical states:
`building_of` retains authored identity, live `structure_owner` requires a present
body, and remembered knowledge retains the state it actually observed. Ordinary
remains also carry an immutable authored source; genuinely dynamic bodies have none.
Appearance lookup and static suppression consume that source directly.

The migrated physical catalogue is explicitly a prototype for existing source boxes.
Its provisional classification is not a real regional/category acceptance. Source
floors, entrances and bays remain absent. Completeness consumers must reject those
unknowns. No Blender build, new appearance binding, model or design was accepted.
Catalogue-versus-materialized provenance verification belongs to future preparation;
complete template/source/art G0 and integrated scene verification remain open.

The original matched native/WASM chain receipts expose a preexisting numeric seam:
initial infantry arrangement differs by one f64 ULP in a member Y coordinate, before
aggregate ownership. That rejected parity arm remains independently identified in
`runtime-numeric-discrepancy.json`; these proofs do not claim universal battle-runtime
parity. Canonical C00 materialization instead uses the shared portable evaluator.

The windowed movement producer also preserves its original physical subset. It filters
whole building owners and ordinary props, then assigns the retained original-order IDs
the dense namespace that the original filtered array used. The frozen subset receipt
pins that authoring boundary; it introduces no runtime conversion or partial owner.

[The focused frame proof](visual/README.md) reaches the shipped garrison scene and
labelled asymmetric/chained-remains states through the real authority and renderer.
It separates capability evidence from unresolved prototype source/art fit.
