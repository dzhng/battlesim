# S0 verdict: full extents require bounded systems

**Verdict:** current native empty worlds can construct/export at the fixed extents, but the full browser battle path fails the allocation gate. Do not shrink 12/15/18 km. Terrain export/drawing, navigation and browser ground storage need focused representation proofs; fog delivery needs a bounded publication contract.

## Frozen baseline

[Identity and hashes](../assets/scale-baseline/identity.json) pin source commit, toolchain, Cargo.lock, wasm artifact, probe inputs and results. [The allocation model](../assets/scale-baseline/allocation-model.json) distinguishes predictions from executed arms. These are empty flat maps at a 4 m height grid, current 8 m fog and 1 m ground cells; they are resource probes, not shipping density or active-battle benchmarks.

The Mac had 48 GiB physical memory and 68% reported free memory at admission. Native arms had a 4 GiB requested-heap ceiling and ran serially. The allocation model admitted each empty-world export and empty-Battle arm before execution. Full browser mesh conversion and full-size first-route arms were rejected from the model; no intentional OOM was executed.

[Raw native stages](../assets/scale-baseline/native/) report elapsed time and allocator live/peak bytes; paired `time` files report RSS, instructions and cycles. Requested heap excludes allocator overhead/caches; RSS is a different measurement. Both southwest and northeast surface queries returned the expected flat ground. Empty Battle performs one step and side switching; it does not allocate navigation or prove opposite-edge movement.

[Browser baseline](../assets/scale-baseline/browser.json) runs the existing WorldView export path on the main thread and a distinct wasm Battle instance in a worker, at 1.6 km. Native/wasm after one step match digest `3dea8a578eccf1cc` and 10,088-byte empty publications. This is a boundary parity check only: an empty state digest is not a proof of map identity or active combat. The public surface queries also match. Browser marks/cleared arrays reproduce the client's exact allocation sizes; they do not instantiate React or measure a rendered frame.

The hardware probe used headless Google Chrome with Metal and reported Apple `metal-3`. Requested device limits match the renderer's max-buffer requests: maxBufferSize/maxStorageBufferBindingSize 4,294,967,292 B; device maxTextureDimension2D 8,192. A default Playwright headless arm returned SwiftShader; it is not used as this Mac's GPU budget evidence. The browser baseline records separate main/worker wasm high-water values and retained JS bytes. No new 3D visual design or asset was created.

## Rejected arms and their owners

| Owner | Source-grounded failure | Focused proof required |
|---|---|---|
| Full ground triangles/export/drawing | `buildTerrainSurface` expands every grid triangle to three 10-float vertices. GPU ground alone is 2.16 / 3.375 / 4.86 GB at 12/15/18 km: all exceed the provisional 400 MB city-buffer increment; Large also exceeds the measured single-buffer ceiling. MeshBuilder first retains 540 / 843.75 / 1,215 million JS numbers, then a typed copy. JS element packing is engine-dependent; an 8-byte double estimate is 4.32 / 6.75 / 9.72 GB, not a measured allocation. | Exact flat ground plus bounded local detail/export/residency, preserving authoritative height/normal/ray and surface classification. |
| Side navigation | Each side retains dense Cell storage, route scratch and at least one vehicle-clearance array. Field-width lower bound is `2 × (16 + 16 + 8) × floor(L/2)^2`: 2.88 / 4.50 / 6.48 GB before world/fog/heap; Medium/Large alone exceed wasm32's 4 GiB address space. Additional stopping ranks and rebuild overlap grow it. | Bounded spatial navigation and search with unchanged known-body, gap, cost and route semantics; opposite-edge moving units. |
| Browser ground | GroundView eagerly allocates four marks bytes plus one cleared byte per 1 m cell: 720 / 1,125 / 1,620 MB even blank. Native truth/known ground uses sparse payload tiles but dense directories and fog-synced arrays; foliage export clones the entire foliage grid. ScarTexture also allocates the full cols × rows texture: every selected size exceeds the measured device 8,192 dimension limit, and Large exceeds the adapter 16,384 ceiling too. | Sparse ground/clearing and bounded learned/export/consumer ownership with exact unseen-change and resync semantics. |
| Fog publication | Every packed record carries the entire fog field: 562,500 / 878,908 / 1,265,628 B before the 88-byte header and other rows. Even blank steady state exceeds the inherited 19.8 KB/tick target. | Initial/snapshot versus bounded incremental delivery, lossless decoder/resubscription parity; cell size alone cannot waive the gate. |
| Duplicate world construction | useStaticWorld constructs a main-thread WorldView beside the worker Battle. Independent worlds and export/copy high-water allocations are real owners. | C33 single prepared authority world with transferred public query/export inputs; camera/picking cannot inspect hidden live destruction. |

Navigation Cell storage is a lower bound from its field sizes, not an ABI measurement. Actual vector capacities, search heap/path growth and layout need recording in the navigation proof. Full-ground tile occupancy is also a bound, not empty residency. Source details and multiplicities are in the allocation model and the systems handoff.

## Consequence for the ladder

G0 records this as an early **failed prerequisite** and creates focused terrain, navigation, ground/clearing and delivery proofs. Dependent full-frame/active measurements remain pending until the representations pass. Systems work may unlock only its individually proven physical/resource contracts under the user's deferred-art scope; complete G0/GG and release appearance gates remain open.

The next pass proves [SA1 exact bounded flat ground/export](../slices/SA1-bounded-terrain.md) first. [SA2 navigation](../slices/SA2-spatial-navigation.md) and sparse ground proofs can run independently in isolated worktrees, with benchmarks serialized. Numeric layout/art coverage is not inferred from these empty maps.
